A tiny Python program that writes one English roast from the AI's point of view. It takes no input and uses only the standard library.

## Run

With Python 3.13, run `python main.py` in the grading environment to write `/output/entry.txt`. For a local run:

```sh
python main.py --output-dir ./output
```

The program creates the output directory if needed and writes `entry.txt` as UTF-8 without a BOM or trailing newline.
